# A2. Пересоздание коммитов

> Нельзя изменить коммит — можно только пересоздать

- `git commit --amend` — заменить последний коммит ветки с изменениями и новым сообщением
- `git commit --amend --no-edit` — заменить последний коммит без изменения сообщения
- `git reset --hard <commit>` — переместить ветку и рабочую директорию
- `git reset <commit>` = `--mixed`
- `git reset --soft <commit>` — переместить ветку, оставить изменения в index
- `git reset --soft HEAD^1` — отменить последний коммит
- `git revert <commit>` — создать новый коммит отмены
- `git revert <commit> -m <parent_number>` — откат merge-коммита
